# 4-Channel-Microring-Resonator-WDM-Interconnect

The WDM transceiver consists of four independent optical channels operating at distinct wavelengths. Each channel is generated by a continuous-wave (CW) laser source and modulated with pseudo-random binary sequence (PRBS) data using a Mach–Zehnder Modulator (MZM). The modulated optical signals are combined using an optical power combiner and transmitted through a common silicon waveguide, forming a wavelength-division multiplexed (WDM) signal. At the receiver, the multiplexed optical signal is demultiplexed using a cascade of microring resonators, which are tuned to a respective resonant laser frequency. 

Key parameters, such as mode index and group index were found using standard wavelength sizes (440nm x 220nm silicon core on silicon dioxide substrate) were simulated in Lumerical MODE. A visualization of the time-domain coupling of the center resonant was created in Lumerical FDTD. The complete system was modeled and verified in Lumerical INTERCONNECT, with signal integrity of all four channels confirmed via eye diagram.
