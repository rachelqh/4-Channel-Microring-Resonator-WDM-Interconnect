# Microring-Resonator-WDM-Interconnect
This project is a photonic reimagining of an electronic continuity test fixture developed during my internship, where the resistances of multiple DUTs were measured to identify short circuits. Unlike an electronic system that relies on relay switching, a photonic implementation could test, read, and process all 13 channels simultaneously, making the measurement almost instant. The overall architecture is a hybrid electronic-photonic device with a custom designed photonic WDM transceiver IC.

The WDM transceiver IC consists of three independent optical channels operating at distinct wavelengths. Each channel is generated by a continuous-wave (CW) laser source and modulated with pseudo-random binary sequence (PRBS) data using a Mach–Zehnder Modulator (MZM). The modulated optical signals are combined using an optical power combiner and transmitted through a common silicon waveguide, forming a wavelength-division multiplexed (WDM) signal. At the receiver, the multiplexed optical signal is demultiplexed using a cascade of microring resonators, which are tuned to a respective resonant laser frequency.
